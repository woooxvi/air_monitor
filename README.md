# STC89C516RD+ 室内环境监测

基于 STC89C516RD+、M702B-U 串口空气传感器和 ST7920 12864 LCD 的室内环境监测示例，使用 SDCC 与 EIDE 构建。

## 功能

- 每秒解析 M702B-U 的 UART 数据帧
- 在 ST7920 12864 上显示 CO2、HCHO、TVOC、PM2.5、PM10、温度、湿度
- 上电前 120 秒显示传感器预热倒计时
- 使用 P3.0/P3.1 硬件 UART 向其他系统输出二进制环境数据帧
- 使用 P3.2 软件串口接收 M702B-U 数据，避免占用下载串口

## 对外 UART 二进制帧格式

发送口为 P3.1，波特率 9600，帧格式如下：

| 字节 | 内容 |
| --- | --- |
| B1 | 0x55 |
| B2 | 0xA5 |
| B3-B4 | CO2 |
| B5-B6 | HCHO |
| B7-B8 | TVOC |
| B9-B10 | PM2.5 |
| B11-B12 | PM10 |
| B13-B14 | 温度，单位 0.01℃，有符号 |
| B15-B16 | 湿度，单位 0.01%RH |
| B17 | B3-B16 低 8 位和 |

## 构建设置

当前工程使用以下 SDCC 关键参数：

- `--iram-size 256`
- `--xram-size 0`
- `--code-size 8192`
- `--stack-auto`

其中 `--stack-auto` 是必须项，用于降低 8051 片内 RAM 的静态分配压力，否则链接阶段会出现 DSEG 空间不足。


## 关于C51的中断
方案| 优先级 | 精度 | 能不能捕获边沿 | 适合用途 | 长代码的影响 |
--- | --- | --- | --- | --- | --- |
主循环轮询 | 最低 | 差 | 很难，容易漏脉冲 | LCD 刷新、传感器业务逻辑 | 仅主循环任务延迟，不干扰中断 |
定时器中断 T0/T1 | 可配置 | 高 | ❌ | 系统时基、软串口 bit 采样 | 中断内代码太长：丢失节拍、采样错位 |
外部中断 INT0/INT1 | 可配置 | 高 | ✅硬件边沿捕获 | 软串口起始位触发(P32/P33) | 中断内代码太长：丢失边沿，丢帧 |
硬件 UART 中断 | 可配置 | 高 | ❌ | 硬件串口收发 | 中断内代码太长：字节丢失 |

## 晶振计算

本工程使用的晶振频率为 11.0592 MHz，主要用于以下计算：

- 机器周期 = 12 / 晶振频率 = 12 / 11.0592 MHz ≈ 1.085 μs
- UART周期 = 1 / UART波特率 = 1 / 9600 ≈ 104.17 μs
- 软件 UART bit 周期 ≈ 105.25 μs (97 个机器周期)
- 软件 UART 半 bit 周期 ≈ 53.17 μs (49 个机器周期)
- 定时器 T0/T1 重载值计算：65536 - (所需时间 / 机器周期)

## 常用位缩写单独说明（你代码高频用到）

1. **TR0**：TCON.4，Timer0 Run control。`TR0=1` 启动T0；`TR0=0`停止T0
2. **TR1**：TCON.6，Timer1 Run control。`TR1=1`启动T1（硬件串口波特率常用T1）
3. **TF0**：TCON.5，T0溢出标志，溢出硬件置1，中断进入后硬件自动清零
4. **TF1**：TCON.7，T1溢出标志
5. **IT0**：TCON.0，外部中断0触发方式。`IT0=1`下降沿触发；`IT0=0`低电平触发
6. **IT1**：TCON.2，外部中断1触发方式
7. **IE0**：TCON.1，外部中断0中断标志
8. **IE1**：TCON.3，外部中断1中断标志
9. **EA**：IE.7，全局中断开关。**EA=1 打开所有使能中断；EA=0 全部中断关闭**
10. **EX0**：IE.0，外部中断0使能
11. **ET0**：IE.1，定时器0中断使能
12. **EX1**：IE.2，外部中断1使能
13. **ET1**：IE.3，定时器1中断使能
14. **ES**：IE.4，串口中断使能
15. **REN**：SCON.4，串口接收使能。`REN=1`允许硬件UART接收数据
16. **TI**：SCON.1，串口发送中断标志，**必须软件写0清零**
17. **RI**：SCON.0，串口接收中断标志，**必须软件写0清零**
18. **SMOD**：PCON.7，串口波特率加倍位。T1模式2作为波特率发生器时，SMOD=1，波特率×2

## 复位默认值（上电复位后）

- P0~P3：0xFF
- SP：0x07
- TCON：0x00
- TMOD：0x00
- TH0,TL0,TH1,TL1：0x00
- SCON：0x00
- IE：0x00（EA=0，所有中断关闭）
- IP：0x00
- PCON：0x00

## 简单示例代码片段

```
TR0 = 1;    // 启动定时器0
TR0 = 0;    // 关闭定时器0
EA = 1;     // 开启全局中断
ET0 = 1;    // 开启T0中断
```
